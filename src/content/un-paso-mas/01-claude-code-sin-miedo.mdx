Todo lo del curso hasta aquí se hace con clics. Esta sección es **opcional** y toca un poco de «código»: abrir un terminal, escribir un par de órdenes y editar archivos de texto. Merece la pena por una razón: **Claude Code**, la herramienta con la que se construyen proyectos como este curso, es el agente más potente y configurable de Anthropic, y su forma de organizarse (archivos `AGENTS.md`, carpeta `.claude/`) es la que inspira skills, Cowork y el resto.

<Callout kind="idea" title="¿Cowork o Claude Code?">
**Cowork** es Claude Code con interfaz amable y pensado para trabajo de oficina. **Claude Code** es lo mismo con más control: le escribes la configuración en archivos, la versionas, la compartes. Si Cowork te cubre, perfecto. Si te pica la curiosidad o quieres montar un espacio de trabajo muy a tu medida, sigue.
</Callout>

## El terminal en cinco minutos

El **terminal** es una ventana donde escribes órdenes en vez de hacer clic. En Mac se llama **Terminal** (búscalo con Cmd + espacio); en Windows, **PowerShell** o **Terminal**. Solo necesitas tres órdenes:

```bash
pwd                       # ¿en qué carpeta estoy?
ls                        # ¿qué hay aquí? (en Windows también vale «dir»)
cd Documentos/Direccion   # entra en esa carpeta («cd ..» sube un nivel)
```

Truco: escribe `cd ` (con espacio) y **arrastra una carpeta del Finder** a la ventana: se escribe la ruta sola.

## Instalar y arrancar Claude Code

Las instrucciones oficiales están en la documentación de Claude Code; a día de hoy, la instalación es una línea:

```bash
# Mac o Linux
curl -fsSL https://claude.ai/install.sh | bash

# Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex
```

Si no te dejan instalar programas en el ordenador del trabajo, pídeselo a IT o pruébalo en casa. La **app de escritorio de Claude** también tiene una pestaña **Code** que hace lo mismo sin terminal.

Luego entra en una carpeta de trabajo y arráncalo:

```bash
cd ~/Documents/Direccion
claude
```

La primera vez te pedirá iniciar sesión con tu cuenta de Claude. A partir de ahí, hablas con él en español, como en el chat, pero **trabajando sobre los archivos de esa carpeta**.

Tres cosas importantes:

- **Permisos.** Antes de crear, modificar o mover archivos, o de ejecutar una orden, te pregunta. Puedes aprobar una vez, aprobar siempre para ese tipo de acción, o decir que no.
- **Esc** para pararle a mitad. **Esc dos veces** para volver atrás en la conversación.
- **Órdenes con barra**: `/help` (ayuda), `/clear` (empezar de cero), `/init` (que cree su archivo de instrucciones para esta carpeta, ver lección siguiente).

## Para llevar

- **Claude Code** es el agente de Anthropic que trabaja sobre una carpeta, desde el terminal o la pestaña Code de la app.
- Tres órdenes de terminal bastan: `pwd`, `ls`, `cd`.
- Se instala con una línea y se arranca con `claude` dentro de la carpeta de trabajo.
- Pide permiso antes de tocar nada; **Esc** para parar; `/help` para ayuda.
